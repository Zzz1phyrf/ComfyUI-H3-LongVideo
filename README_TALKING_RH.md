# MiniMax H3 · Talking Avatar

2026-10-28 当前分享入口为13口播（可选本地/RH），对应15号RH计算模板；14仅为可选精简控制画布。新版口播仅接一张人物连场景参考图。独立Ref2VA各段不传上一段latent；单段重做仅更新目标段及左右接缝。旧多图/latent接口留在Legacy节点。详见[独立分段操作与验收边界](TALKING_OVERLAP.md)。

新分析优先找原声停顿，在4–15秒范围内分段；没有可用停顿的切点明确提示按时长兜底。波形支持拖动、增加和删除切点，手动保存的切点优先，旧项目不自动重算。提示词直接在每段展开区域编辑，保存不生成。画布显示项目进度；RH异常任务恢复仅用于绑定已存在而本地缺失的任务ID。停顿分段与独立片段的姿态连续性是两项不同问题，当前跨段画面仍需人工验收。

分辨率在外部`ResolutionSelector`预设节点调整，将width/height连接到口播控制节点；控制节点不再提供内部MP选项或固定竖屏比例。预设倍数使用32，新项目冻结实际宽高供所有段执行及校验，修改尺寸需新建项目。已有MP项目保持原尺寸；使用更新后的13/14示例，或通过`scripts/migrate_talking_resolution.py`的`migrate`函数转换旧JSON。旧保存画布的seed、提示词和项目绑定保留。

以下为保留的旧版 latent 续接说明；独立窗口的参数、预览、重做及合并规则以新文档为准。

同一口播节点默认本地生成，可选RunningHub。两者共用完整音频分段、试听审核、原图参考条件、动作续接、裁切和最终合并。新项目不使用人物空间遮罩；完整片颜色和画质稳定性尚未验收。歌曲视频使用MV Generator及配套MV Prompt Expander，旧MV节点的口播入口已移除。当前为测试候选，GitHub尚未推送。

## 已完成段重做与恢复

审核面板的已完成段提供“重做本段及后续”。点击只准备重做，再点“开始 / 继续生成”才执行；本段及全部后续依赖段待更新，前面的片段继续复用。沿用原seed、音频与冻结配置，不自动换种子。旧片段、旧成片及任务记录保留，本地每次尝试使用独立音频入口，避免重做误用旧采样缓存。

重做中断后可继续原任务；明确失败时用“重试失败段”。需要放弃当前重做时，点击“恢复重做前结果”恢复整条旧结果链和成片状态，新尝试的记录也保留。创建结果未知或任务仍在运行时先查询或绑定任务ID，不能直接恢复而丢弃任务。恢复前校验旧片段、原声、参考素材、配置及旧成片哈希；文件变化会停止。一次重做结束或恢复后才可改切点或开始另一轮重做。

展开画布生成完各段后仍须显式运行Talking Merge，合并成功才结束这次重做；合并失败不重复采样，可重试合并或恢复旧结果。内置本地/RH模式沿用自动合并。此功能仅在候选源码中，未覆盖正式安装；它不修复长口播的画质劣化。

## 本地生成

Ref2VA新项目会在提交前核对条件、帧率、零罩原声、续接分支和实际保留尾部时钟；尺寸/帧数脱离项目时钟、视频误接音频VAE或错误前缀范围会明确停止。RH参考人声和零罩原声使用同一音频VAE，不再静默改写不一致的云端连接。已有Ref2VA项目恢复仍核对其保存的执行行与审核时钟，旧非Ref2VA项目保留原契约。

内置与展开入口共用条件音频切片，保留视频时间量化后最多半帧的原声尾部采样。视频切点、39帧上下文、12token续接和采样配方不变；这些修复与校验不构成长片肤色或纹理通过的证明。

使用[Ref2VA本地展开工作流](examples/09_H3口播_Ref2VA本地展开.json)：画布展开真实模型加载、原版Avatar、音频零遮罩、首段与续段Ref2VA条件、latent续接、VAE解码、原片保存、分段裁切预览及最终合并。模型和采样参数直接在对应节点选择或调整，实际执行使用当前画布快照。续接分支和四个模型加载门控使用已有KJ LazySwitch，准备分段时不加载大模型。

新增[Ref2VA标准K本地展开工作流](examples/10_H3口播_Ref2VA标准K本地展开.json)用于独立对照：Ref2VA pruned INT8主模型、Ref2V Turbo4 LoRA、simple4/res_multistep、cfg1、原生SamplerCustom。采样、解码、保存均为真实画布节点。此组合在本轮40.87秒8段测试中避免了旧FL2VA+Turbo8组合的明显推近，但后半段脸部细节仍变软，整体验收未通过；单换K采样而保留旧模型组合并未修复推近。09和已有项目保留。RH候选也支持读取原生SamplerCustom配置，完整片画质验收单独记录。

选择音频、人物图和已安装权重，保持执行方式“画布”。第一次“运行”只准备分段；试听、调整并确认后，在审核面板点击“开始/继续生成”。各段实际保留的画面和对应原音频显示在“本段预览”保存节点，审核面板每段也可点击“预览视频”。各段完成后回画布再次运行，Talking Merge调用插件真实裁切合并，再由原生SaveVideo保存和预览完整片。画布中的完整原片保存节点用于诊断和最终合成，不是裁掉上下文的分段预览。

模型、采样参数或接线改变后新建项目；切点改变需重新确认。新项目不生成、读取或上传人物遮罩图片，不需要分割模型；旧项目恢复保留原配置，要切换无罩方式需新建项目。新项目首段与续段均使用原生Ref2VA：分段音频经AudioSeparation的人声输出进入参考音频端，原始分段音频同时编码为零噪声罩音频latent。SelfLift首段scale0.5，续段scale1.0；标准K不使用该倍率。两者保留39帧上下文与实际保留尾部12token，保存后的输出前缀须逐值一致。标准K在解码和保存前验证并恢复仅浮点格式往返造成的微小前缀误差，明显变化会停止，不修改新生成区域。旧项目按原契约恢复。本地示例默认首段6秒以便短片验证，不承诺长首段显存占用。

下方三节点方式为兼容的内置模式，也是RH入口；它不展示本地采样链路。两种方式均保留原版Avatar和音频零罩，不能把内置模式误当作展开画布。

1. 在独立测试用ComfyUI中只加载一份本插件，安装requirements.txt，让FFmpeg、FFprobe可从PATH访问。本地生成还需要SelfLift-Avatar、KJ、YC MiniMax-H3及相应原生H3节点。
2. 内置模式导入examples/05_H3口播_一镜到底.json，加载完整音频和带背景的人物主图；展开模式使用上面的09示例。新项目没有人物活动范围，不需要MASK图片或轻量分割模型。
3. backend选择“本地”，明确选择local_model、local_clip、local_video_vae、local_audio_vae、local_upscaler，需要时选local_lora。仅使用ComfyUI已有权重。本地不填写workflow_id，不需要RH Key或网络，失败时不会自动转到收费云端。
4. 运行节点仅准备项目。审核面板中试听、微调，保存切点后再次试听实际对齐落点，再点“确认分段”“开始/继续生成”。
5. 各段在当前ComfyUI原生队列执行，后段使用前段实际保留尾部的原生latent续接；完成后自动裁切合并。面板可播放成片，重新运行同项目节点可刷新final_video输出路径。

模型与可选LoRA是显式配置，基础8步需与所选模型匹配。本地不会自动下载、融合或替换权重；没有云端同款权重时，只能分别验证效果，不能声称两边画质一致。

此前内置模式测试过[MATLOWAI的融合模型](https://huggingface.co/MATLOWAI/minimax-h3-fused-turbo-int8-convrot)：`minimax_h3_fused_refdelta_r1024_turbo8_mystic07_int8_convrot.safetensors`，`local_lora`选择“不使用”，该文件已融合Turbo。该历史组合不代表本轮展开画布的实际配置；以各项目冻结图和真实执行记录为准。此前本机hybrid b20-49／FL2VA pruned配单独Turbo 8step的替代组合也曾出现闭嘴，文件可加载不等于口型已验证，不能当作等价替换。

本地短片测试显式采用首段6秒、后续5.667秒、seed999，实际切点5.875秒；这是测试配置，不是所有硬件的显存保证。长首段、完整音频和更多素材仍需逐项复核。

local_clip_read默认“原生”。本机实测遇到Windows大CLIP文件映射读取时原生崩溃，因此提供“内存”方式：仅此口播图的CLIP分支从原文件逐张量读取相同字节，保留dtype和元数据，不修改全局CLIPLoader、Avatar或权重文件，可能占用更多系统内存。没有此问题时保留原生读取。

选择“内存”时，同一进程仅保留一份对应文件的CLIP实例供各口播项目复用，避免准备新项目使队列缓存淘汰后重复加载32B编码器。文件路径、大小或修改时间改变时替换，重启后释放；即使队列空闲也可能保留约25GB系统内存。原生读取模式不使用这份缓存。

## 可选RunningHub

backend选择“RunningHub”，填写有权调用的workflow_id，选择海外/国内站与实例类型；local_*权重选项不参与此模式，本机无需H3模型。点击口播节点的“RH API 设置”，选择对应站点填写Key并保存，即时生效。MV和口播共用此配置；密码不回显、不进入工作流。未设置本机Key时仍支持RUNNINGHUB_API_KEY环境变量（可选高级用法），例如PowerShell：

```powershell
$rhSecret = Read-Host 'RunningHub API Key' -AsSecureString
$env:RUNNINGHUB_API_KEY = [Net.NetworkCredential]::new('', $rhSecret).Password
# 接着在此终端中启动ComfyUI
```

Key仅由节点设置弹窗保存到本机用户目录，不进入节点序列化数据或工作流。新建RH项目时读取所填工作流的实际API图，冻结模型/LoRA及强度、模型补丁、CLIP/VAE、Avatar参数和sampler/sigma完整链路；不再用内置Turbo、步数、倍率或Sigma Refiner覆盖。读取失败或链路不支持时明确停止，不回退到内置配置。审核面板显示冻结配置；修改RH设置后新建项目，恢复已有项目仍使用其原快照。

RH采样主干支持唯一的SelfLiftAvatarH3Sampler或原生SamplerCustom；标准K使用noise_seed，不套用SelfLift倍率、transition或tiling设置。[11云端标准K模板](examples/11_H3口播_Ref2VA标准K_RH云端模板.json)包含Ref2VA pruned BF16 + Ref2V Turbo4、simple4/res_multistep、cfg1及音频零罩，可另存至RH，再把新workflow_id填入本地05入口。模板素材是占位文件，实际分段任务由本地控制器上传；原有RH工作流不必修改。

标准K的RH返回latent保持原文件不变：先检查前12token仅有rtol=atol1e-6范围内的浮点误差，再另存逐值匹配上一段尾部的carry；新生成区域和其他张量不变。超差、非有限值或缓存变化会停止；恢复时同时校验原始返回和carry哈希。SelfLift仍要求原始返回前缀逐值一致。此数值处理不修复人物纹理、肤色或果冻效应。

节点上显式选择的分辨率和seed、逐段音频/帧数、固定口播提示词及现有首段/后段续接由口播项目绑定，审核页与执行核验分别列明；这些项目输入与RH采样主干区别保存。RH侧还需现有H3、Avatar及口播续接用KJ/LTX节点。每个独立任务显式上传该段音频、参考图和上段latent，不依赖RH保持同一进程或临时目录；只有旧有罩项目上传其原遮罩。控制节点不需要上传到RH；本地做分段审核与最终合并，确认后点击开始才创建付费RH任务。历史无RH快照项目保留原执行方式，不静默升级。

## 人物遮罩和续接

新项目不使用人物轮廓或背景冻结范围。全白通用视频生成罩仅表示整个新画面可生成，后段再将前12token时间范围设为0以保留上下文；音频latent仍使用全零噪声遮罩。这三种含义不同，去掉人物空间罩不等于删除音频零罩或时间前缀。原始参考图约束身份、服装与场景，不能保证每帧背景几何严格固定。

本地展开画布的video_generation_mask输出沿用旧person_mask槽位，内容为全白，不需要人物识别。已有自动或手工空间罩项目保留旧执行契约；下方分割依赖仅用于恢复旧自动罩项目，新无罩项目不调用它。

旧自动罩使用MediaPipe SelfieMulticlass在CPU上识别原始主参考图，向外留运动余量并羽化。每张原始图生成一次并缓存，各段共用，不从生成尾帧反复识别。

安装requirements.txt中的mediapipe，将官方模型`selfie_multiclass_256x256.tflite`放到`ComfyUI/models/mediapipe/`；支持同名extra_model_paths目录。已有模型直接复用，不自动联网下载，插件包不包含权重。官方[模型说明](https://developers.google.com/edge/mediapipe/solutions/vision/image_segmenter#multi-class_selfie_segmentation_model)、[下载地址](https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_multiclass_256x256/float32/1/selfie_multiclass_256x256.tflite)。首次识别失败会停止准备并提示换图，不默认用全黑或全白代替。自动活动范围仍需通过实际视频检查，不能保证任意构图和大幅手势都适用。

为恢复旧项目，服务端仍接受旧工作流已连接的person_mask；旧接线保留，新节点隐藏该兼容接口。旧项目继续用其原罩，不悄悄改成无罩。自动缓存位于输出目录`H3LongVideo/口播/mask_cache`，按原图、模型SHA256及算法版本区分；旧项目保存实际PNG及哈希。缓存损坏或输入变化时保留旧项目，按提示新建。

MASK可与主图或最终画面同尺寸。1.0 MP/9:16为768×1376，0.8为672×1216，0.6为608×1056；与主图同尺寸时按相同中心裁切映射。近白/近黑内部值规范为纯白/纯黑，保留羽化过渡。

两种后端都保留音频零噪声遮罩和固定提示词，不修改原版Avatar。RH采样参数以项目冻结的云端SelfLift或SamplerCustom配置为准；旧内置本地模式仍使用其原有参数，展开本地模式采用真实画布，09使用SelfLift，10使用原生标准K。新项目全段Ref2VA，保留39帧对应的12个原生latent token。reference_2至reference_6保留多图条件，其完整片画质尚未验收。旧06示例用于恢复历史项目。本地与RH均须安装audio-separation-nodes-comfyui，并已有HDEMUCS权重。

目标时长仅为声学建议。切点按H3续接网格对齐，最大偏移约0.354秒，须试听实际落点。首段非末段至少2.333秒、最多13.667秒，后段最多12.75秒。末段保留全部有效音频样本；尾部token索引由实际保留区间计算。

## 暂停与恢复

后端、图像、遮罩、模型或配置改变后，点击“新建项目”再运行，旧项目与片段保留。改切点使变化位置及后续依赖段失效，原文件仍保留。“暂停后续生成”会收集当前段，再停止提交下一段。

项目在输出目录H3LongVideo/口播/projects，成片在H3LongVideo/口播/final_videos。本地与RH均使用该口播分类目录；内部节点ID保持兼容。

本地先落盘prompt_id再入队，完成记录持久保存。若采样时重启使任务从ComfyUI队列/历史消失，会明确停止并保留文件，检查后手动重试，不自动重排。

RH中断恢复和下载失败均查询同一taskId。创建结果未知时不自动重建，先核实RH任务列表，再在异常恢复处绑定已有ID。明确失败才手动重试。旧RH候选画布导入时保留RH后端和项目ID。
