# H3口播 · 本地控制 / RH生成（候选版）

在原插件中新增独立节点 `H3LVTalkingRH`。本地只负责准备素材、声学分段、试听审核、任务状态和FFmpeg合并；H3模型在RunningHub运行。原MV/长视频节点保留。此版本用于独立实例测试，尚未发布或覆盖正式插件。

## 使用

1. 在测试用ComfyUI中只加载一份本插件，安装requirements.txt，并让FFmpeg、FFprobe可从PATH访问。本机无需H3权重。不要同时加载此候选与旧版插件，二者包含相同的旧节点ID。
2. 在启动ComfyUI的进程环境中配置自己的 `RUNNINGHUB_API_KEY`。Key不填进节点，不保存在工作流中。PowerShell示例：

   ```powershell
   $rhSecret = Read-Host 'RunningHub API Key' -AsSecureString
   $env:RUNNINGHUB_API_KEY = [Net.NetworkCredential]::new('', $rhSecret).Password
   # 接着在此终端中使用你自己的命令启动ComfyUI
   ```

3. 导入 `examples/05_H3口播_RH本地控制.json`，加载完整口播音频、带背景的人物主图、人物活动遮罩。主图连接IMAGE；灰度遮罩通过ImageToMask的red通道连接person_mask。
4. 填写有权调用的RH工作流ID，选择海外/国内站。RH侧需要模板所用的H3、Avatar、LMS、KJ和LTX节点及权重。云端单段API模板位于 `defaults/talking_rh_graph.json`；本地控制器提交完整模板，不依赖云端保存图中的旧图片文件。它会实际创建付费RH任务。
5. 保持1.0 MP、seed999、ultra默认，运行本地口播节点，打开分段审核。首次运行只准备项目，不提交RH生成。
6. 在波形或结束时间框调整切点，点击“保存切点”，试听对齐后的实际落点，再点击“确认分段”“开始/继续生成”。每段音频、图、遮罩、上段原生latent显式传入RH；无需RH驻留同一进程。
7. 完成后在面板内播放完整片，或使用节点的final_video路径。重新运行同一项目节点可刷新输出路径。项目保存在ComfyUI输出目录的 `H3TalkingRH/projects`，完整片在 `H3TalkingRH/final_videos`。

## 人物活动遮罩

白色允许人物及手势活动，黑色保留原图背景，边缘留有柔和过渡。建议包住头发、肩膀、双手以及预期活动余量。MASK尺寸可与主图相同，也可与最终画面相同；1.0 MP/9:16输出为768×1376，0.6为608×1056。与主图同尺寸时，控制器按相同中心裁切映射。

首版需要显式手动遮罩，不含自动分割；每张参考图设定一次，各段自动复用。近白/近黑内部值会规范为纯白/纯黑，保留中间羽化过渡，以兼容本机新版图片加载器。

## 参数和条件

- 保留原版SelfLift-Avatar、音频零噪声遮罩、LMS、lowres_scale0.8、基础8步、transition5、rho0及固定提示词。没有K采样或付费扩写服务。
- 主图决定静态背景。单图首段使用同图首尾条件，后段Ref2VA＋39帧对应的12个原生latent token续接。
- 可选reference_2至reference_6保留Ref2VA多图条件。多图首段使用Ref2VA；该模式接线有自动测试，尚未获得多图完整片画质验收。已获稳定性正面反馈的完整片为单主图方案。
- 首段、后段目标时长只是声学分段建议。保存时按H3续接网格对齐，最大偏移约0.354秒，必须试听实际落点。首段非末段至少2.333秒、最多13.667秒，后续段最多12.75秒。最后一段保留完整有效音频样本。
- 图像、遮罩、分辨率或其他节点配置改变后，点击“新建项目”再运行，旧项目和片段保留。手动改切点会使变化位置及后续续接段失效，旧文件仍保留。

## 暂停与恢复

“暂停后续生成”会收集当前段，再停止新提交，不会取消已产生费用的RH任务。重启本地ComfyUI后，保留project_id，打开面板并继续；控制器查询已保存任务ID。下载失败也继续获取同一任务。明确失败或被拒绝时，可手动点击该段“重试失败段”。

创建请求结果未知时不会自动重建。先去RH任务列表核实，在“异常任务恢复”里填写段号和已存在的任务ID，再继续查询。遇到此状态应保留整个项目目录。

## 验证范围

此节点是本地控制端，不是把整套交互面板部署进RH网页。任务链、暂停/恢复、真实裁切合并、失败处理和旧节点回归由自动测试与独立ComfyUI验证；真实短片和任务证据保存在本轮开发实验目录。采样方案先前男女完整片获整体稳定性正面反馈，但轻微人物细节漂移仍存在，不承诺零劣化或任意素材一镜到底。

本地候选包不含Key、模型、音频、参考图、实验视频或开发机路径。首次给粉丝分发前，仍需在另一台机器验证安装、Key配置、导入和生成。
