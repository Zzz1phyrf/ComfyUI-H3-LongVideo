# 口播数字人使用说明

导入 [口播完整示例](examples/MiniMaxH3口播数字人工作流%20By%20像素幻想Lab.json)，选择自己的音频、参考图和模型。RH 使用自己另存的配套首尾锚定工作流ID。旧编号示例不再分发。

## 当前生成方式

新项目使用原图首尾锚定：参考图先按输出尺寸统一裁切缩放，同一张规范图供每段首尾使用，音频按分段提供，不继承上段 latent。原始图片另行保留。既有项目沿用原来的图像处理和执行策略，不自动迁移。

完整本地画布包含音频、图片、尺寸、Talking Avatar、模型/LoRA、首尾条件、音频条件、标准 K 采样、解码和保存。实际参数来自画布连接。RH 模式使用配套的云端首尾条件单段图，本地负责审核、任务、下载、预览和合并。

## 操作

1. 选择完整音频与人物参考图；按需求选择直接使用音频或提取人声。
2. 选择本地或 RunningHub。RH 填自己的工作流 ID、区域和实例，保存 Key 后检查配置。
3. 准备分段，试听并检查切点；保存确认后开始生成。
4. 检查分段效果。只需重做一段时在该段操作，其他成功段继续复用；旧结果保留。
5. 全部分段完成后自动合并，或使用“仅重新合并”。暂停/停止会等当前已提交任务完成。

生成时长需要遵循首尾模型的帧网格。最终片按 24fps 编辑时钟、分段实际保留长度和完整原声合成。短补齐音频不代表实际成片延长或慢放。

## 旧项目与故障

旧节点、旧输出槽、旧任务记录路径和执行快照继续兼容；不要删除旧项目仍需的外部节点。运行中的未知 RH 任务先核实并绑定原 ID，不重复提交。错误时下载节点的错误日志，详细行为见 [RH 执行与恢复](MV_RUNNINGHUB.md)。

当前方案优先稳定构图、衣色和画面尺度；相似手势、回到参考姿态及口型自然度仍需逐片检查。
