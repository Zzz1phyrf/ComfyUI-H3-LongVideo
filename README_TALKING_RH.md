# 口播数字人使用说明

导入 [口播完整示例](examples/MiniMaxH3口播数字人工作流%20By%20像素幻想Lab.json)，选择自己的音频、参考图和模型。RH 使用自己另存的配套首尾锚定工作流ID。

## 当前生成方式

参考图按输出尺寸统一裁切缩放，各段使用同一张图作为首尾约束，并配合对应音频生成。原始图片保留。

完整本地画布包含音频、图片、尺寸、Talking Avatar、模型/LoRA、首尾条件、音频条件、标准 K 采样、解码和保存。实际参数来自画布连接。RH 模式使用配套的云端首尾条件单段图，本地负责审核、任务、下载、预览和合并。

## 操作

1. 选择完整音频与人物参考图；按需求选择直接使用音频或提取人声。
2. 选择本地或 RunningHub。RH 填自己的工作流 ID、区域和实例，保存 Key 后检查配置。
3. 准备分段，试听并检查切点；保存确认后开始生成。
4. 检查分段效果。只需重做一段时在该段操作，其他成功段继续复用；旧结果保留。
5. 全部分段完成后自动合并，或使用“仅重新合并”。暂停/停止会等当前已提交任务完成。

只换参考图不需要重新分析音频。面板显示本次实际使用的图片，点击“同步画布参考图（保留切点）”可单独更新；开始生成前也会自动核对。尚无生成记录时直接更新，有生成记录时确认后建立使用新图的新版本，保留音频、已保存切点和提示词，旧项目与视频保留。运行中的任务固定使用开始时的图片；更换音频或生成配置仍需重新分析。

生成时长需要遵循首尾模型的帧网格。最终片按 24fps 编辑时钟、分段实际保留长度和完整原声合成。

## 旧项目与故障

已有项目可继续使用，请保留其依赖的外部节点。运行中的未知 RH 任务先核实并绑定原 ID，不重复提交。错误时下载节点的错误日志，详细行为见 [RH 执行与恢复](MV_RUNNINGHUB.md)。

当前方案优先稳定构图、衣色和画面尺度；相似手势、回到参考姿态及口型自然度仍需逐片检查。
