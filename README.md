# ComfyUI H3 Long Video

用于 MiniMax H3 的长音频分段生成插件，支持唱歌数字人与口播数字人。导入音频后，插件自动分析分段、安排镜头，提供试听和编辑界面；确认后依次生成各段视频，并配回原音频合成为完整成片。

## 主要功能

- **自动分段**：根据音频分析结果和目标时长划分片段，支持试听与调整切点。
- **两种表演模式**：唱歌模式安排运镜和景别变化；口播模式保持参考构图与固定机位。
- **镜头简报编辑**：逐段查看、修改镜头方案和表演节奏。
- **顺序生成**：自动提交各段任务，支持暂停、继续和失败重试。
- **局部重做与合成**：单独重生成某段、恢复上一版，或使用现有片段重新合成。

## 安装

1. 将本仓库克隆或解压至 `ComfyUI/custom_nodes/ComfyUI-H3-LongVideo`。
2. 在 ComfyUI 使用的 Python 环境中安装本插件的 `requirements.txt` 依赖，并确保 `ffmpeg`、`ffprobe` 可用。
3. 重启 ComfyUI，导入 [一体化示例工作流](examples/04_H3长视频_单节点一体化.json)。
4. 安装示例所需的外部节点：`comfyui-vrgamedevgirl`、`ComfyUI-Prompt-Assistant`、`ComfyUI-VideoHelperSuite`、`ComfyUI-KJNodes`。
5. 在工作流中选择已安装的 MiniMax H3 Ref2VA、LoRA、VAE 和 CLIP 权重，并配置提示词小助手的模型服务。

示例已连接各节点，并内置 V5 唱歌／口播扩写规则。默认使用 Ref2VA 配合 Turbo LoRA，采样配置为 `euler / beta / 10 步`，分辨率为 `960×544`；可根据素材方向和显卡条件调整。

首次音频分析会按需下载语音识别模型。唱歌模式未连接独立人声时，还会下载约 319 MiB 的人声分离模型。模型下载完成后保存在本地，后续分析优先复用。

## 快速开始

### 1. 准备素材

加载完整歌曲或口播音频，将其连接到 **H3 长视频 · 音频分析与顺序生成** 节点的 `audio`。已有分离人声时，可连接可选输入 `vocals`。

参考图连接到工作流中的 **MiniMax H3 Reference To Video** 节点。在提示词小助手的素材说明中填写图片用途，例如：

| 素材组合 | 素材说明示例 |
| --- | --- |
| 一张带背景的人物图 | 图1是人物和背景的完整参考图。 |
| 人物图＋场景图 | 图1是人物，图2是场景。 |
| 人物三视图＋场景图 | 图1是同一个人物的三视图，图2是场景。 |

使用单图时，关闭或断开第二张参考图输入。需要全身镜头时，建议提供包含完整服装与双脚的人物参考。

### 2. 设置模式与镜头

| 参数 | 作用 |
| --- | --- |
| `mode` | `singing` 为唱歌；`speaking` 为口播。 |
| `target_seconds` | 每段的目标时长，实际切点根据音频调整。 |
| `max_seconds` | 单段允许的最长时长。 |
| 镜头活跃度 | 唱歌模式下，`auto` 按音频能量安排，`moderate` 采用较轻运动，`dynamic` 安排明显的横移、环绕或推拉。 |
| 最远允许景别 | 限定唱歌镜头的取景范围。需要近景、中景及全身变化时，选择 `full shot`。 |

唱歌模式每段安排一种主要运镜，人物可随表演和镜头移动偏离画面中心。口播模式沿用参考画面的人物位置、尺度和裁切范围，保持固定机位。

“运镜规则：查看与修改”用于调整当前模式的镜头规划规则；提示词小助手中的扩写规则用于将镜头简报转换成视频提示词。

### 3. 分析并确认

首次点击 ComfyUI 的“运行”，插件会分析音频并打开分段审核面板。

1. 试听各段音频，检查切点。
2. 查看每段的“镜头方案”和“表演节奏”，按需修改。
3. 点击“保存并确认”。

长音频可先点击波形选中分段，再点“当前段”或“切点附近”放大。拖动彩色切点线调整时间，用下方滑条横向浏览，点“全曲”恢复总览。也支持双击局部放大、Ctrl / ⌘ + 滚轮缩放和 Shift + 滚轮横移。放大至单段时长范围内会加载原曲与人声的精细波形；已有项目无需重新分析。点击波形不会自动滚动到分段卡片。

修改模式、分段时长或镜头参数后，点击节点上的 **“重新分析并分段”**，让新设置生效。

### 4. 生成与导出

确认分段后，点击审核面板的 **“开始顺序生成”**，或运行整张工作流。插件依次生成各段视频，完成后自动合成并配回原音频。

最终成片保存在：

```text
ComfyUI/output/H3LongVideo/final_videos
```

项目音频和分段视频保存在：

```text
ComfyUI/output/H3LongVideo/projects
```

## 暂停与修改

- **暂停／停止后续生成**：当前片段完成后暂停提交新任务。
- **继续生成**：沿用该项目已保存的生成设置。
- **重新生成本段**：使用当前画布设置重做所选片段；新版本成功前保留旧版本。
- **恢复上一版**：恢复该段上一次成功的视频。
- **仅重新合成**：使用现有片段合成成片，无需重新生成视频。

修改某段镜头简报会将该段标记为待重生成；调整切点会影响切点两侧的片段，需要重新确认分段。需要重新划分段数时，调整时长参数后重新分析。

## 提示词扩写

示例工作流的文本连接为：

```text
镜头简报 → 提示词小助手 → H3 视频提示词
```

唱歌和口播共用一份 V5 扩写规则，根据模式分别处理运镜和固定机位要求。规则包含参考图角色分配、场景连续性、人物身份、服装原始颜色及无新增字幕等约束。

扩写内容在提示词小助手中维护。示例已开启“自定义规则”并内置全文，也可复制 [V5 规则文本](ref2va_performance_rule.txt) 到小助手中使用。节点的“运镜规则”负责镜头规划，小助手负责最终扩写。

自行搭建工作流时，也可将 `segment_brief` 接入其他文本处理节点。顺序生成工作流需保留一个 `H3LVUnified` 节点和一个 VHS Video Combine 输出节点。

## 使用建议

- 当前面向单人口播和单人唱歌；建议先生成少量片段，确认素材与模型配置合适。
- 唱歌识别可能出现错字或切点偏差，生成前应试听分段。
- 参考图尽量提供清晰、完整的人物与场景信息。上半身参考中的下装可能由模型补全。
- 景别、运镜幅度、服装和场景保持由生成模型实际执行，需检查成片。片段之间采用剪辑衔接，不保证无缝长镜头。
- 保留项目文件夹可继续重做片段和重新合成；只需交付成片时，导出最终 MP4 即可。
